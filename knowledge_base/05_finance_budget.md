# 星辰科技有限公司 2026 年度财务预算报告

本报告为虚构示例数据，仅用于星辰科技内部知识库演示。

## 1. 预算总览

2026 年度公司运营预算总额为人民币 52,000,000 元，按日历年度编制。预算较 2025 年实际支出增长 8%。

| 类别 | 预算金额（元） | 占比 |
| --- | ---: | ---: |
| 人员成本 | 28,000,000 | 53.8% |
| 研发与云资源 | 8,000,000 | 15.4% |
| 市场与销售 | 7,000,000 | 13.5% |
| 行政与办公 | 4,000,000 | 7.7% |
| 客户成功 | 2,000,000 | 3.8% |
| 预备金 | 3,000,000 | 5.8% |
| 合计 | 52,000,000 | 100% |

人员成本包含基本工资、绩效奖金、社会保险和住房公积金。2026 年末员工计划由 200 人增至 230 人。

## 2. 研发与云资源预算

研发与云资源预算 8,000,000 元，其中“星云知识库问答”项目预算 1,200,000 元：

| 项目 | 金额（元） |
| --- | ---: |
| GPU 推理服务器 2 台 | 360,000 |
| 向量检索与存储基础设施 | 180,000 |
| 大模型 API 调用费用 | 300,000 |
| 数据安全与审计工具 | 120,000 |
| 外部实施与评测服务 | 240,000 |
| 合计 | 1,200,000 |

## 3. 审批权限

| 单笔金额 | 审批人 |
| --- | --- |
| 5,000 元及以下 | 部门负责人 |
| 5,000—50,000 元 | 财务负责人 |
| 50,000—500,000 元 | 首席执行官 |
| 500,000 元以上 | 董事会 |

财务负责人为周明远，首席执行官为陈星河。

## 4. 报销标准

- 员工应在费用发生后 30 日内提交报销申请，并附合规发票。
- 市内交通据实报销；出差优先选择高铁二等座或经济舱。
- 住宿标准：上海地区每晚不超过 600 元，其他城市每晚不超过 450 元。
- 出差餐补每人每天 100 元。
- 工作日 20:00 后加班餐补 30 元；22:00 后加班出租车费单次不超过 100 元。

## 5. 预算执行与监控

- 财务部每月 5 日前发布上月预算执行报表。
- 各季度末进行预算复核，偏差超过 10% 的科目须提交说明。
- 预备金使用须经财务负责人和首席执行官共同批准。
- 年度审计由外部会计师事务所执行，审计报告提交董事会。
